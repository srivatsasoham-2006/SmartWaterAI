Sensor Monitoring

View water quality measurements from connected devices.

pH Sensor

Measures acidity or alkalinity after appropriate calibration.

Turbidity Sensor

Estimates water cloudiness using the sensor's characteristics.

TDS Sensor

Estimates total dissolved solids according to the sensor specifications.

Temperature Sensor

Measures water temperature, which can affect other measurements.

Dissolved Oxygen Sensor

Measures dissolved oxygen using a suitable calibrated module.

Data Connection

Sensor readings require a connected device or a configured data source.

Important Note

Sensor measurements and AI predictions require calibration, validation, and suitable reference criteria. This interface alone cannot establish potability or certify that water is safe to drink.
